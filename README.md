# 🇵🇭 Filipino Food Guide

> *"Learning web development, one Filipino dish at a time."*

## 📖 About

The **Filipino Food Guide** is a personal web application built with **HTML**, **CSS**, and **JavaScript**. I created this project not only to practice front-end web development, but also to document my journey of learning how to cook Filipino dishes.

Every time I learn a new dish, I can add it to this guide along with information such as its description, category, region of origin, ingredients, and cooking method. Over time, I hope this project becomes both a growing collection of Filipino cuisine and a reflection of my progress as a home cook and developer.

## 🎯 Goals

This project aims to:

* 📚 Practice front-end development using vanilla HTML, CSS, and JavaScript.
* 🍳 Keep track of the Filipino dishes I've learned to cook.
* 🇵🇭 Learn more about Filipino cuisine and its regional diversity.
* 💻 Apply programming concepts through a real-world personal project.
* 🌱 Continuously improve both the application and my development skills.

## ✨ Planned Features

* Browse Filipino dishes
* Search for dishes
* View detailed dish information
* Organize dishes by category
* Track the dishes I've learned to cook
* Responsive design for different screen sizes

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript

## 📌 Project Status

🚧 **Currently in Development**

This is a passion project that will continue to grow as I learn more recipes and improve my web development skills. Every new dish I learn is another opportunity to expand both this guide and my knowledge.

## 🌟 Why This Project?

There are plenty of recipe websites on the internet, but this one is different—it's **my personal cooking journal**.

Instead of collecting every Filipino dish I can find, this guide focuses on the dishes I've personally learned to cook. It's a way to combine two things I'm passionate about: learning to build software and learning to cook Filipino food.
