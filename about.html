About This Project

Filipino Food Guide is a personal web development project created to document the Filipino dishes I've learned to cook.

🍲 Why I Built This

I wanted a project that would help me practice front-end web development while keeping track of the Filipino dishes I've learned to cook.

Instead of building another generic sample website, I decided to create something personal that I can continue expanding as I learn more recipes.

💻 Technologies Used

  • HTML5
  • CSS3
  • Vanilla JavaScript
  • Git & GitHub

🚀 Future Plans

  • Include cooking notes.
  • Add recipe difficulty levels.
  • Add preparation and cooking times.
  • Filter dishes by category.
  • Improve the overall design.
